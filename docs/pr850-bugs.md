DupeSearch), and their fix status. Each bug is reported to the "update PR850" session, which reports back the
fixing commit. Fixed bugs are pushed to [PR 850](https://github.com/nzbgetcom/nzbget/pull/850) at `58ed2bb3` or later.

B1–B30 were reported fixed by `d4ca8482`. An independent review rates B9, B16, B17, B24 and B30 as partial fixes, with follow-ups B31–B38. Former known limit, now removed: history items' completed-file states used to be rewritten in the upstream format only when touched, so upstream nzbget couldn't retry them after a downgrade. `ce585285` converts every format-8/9 file state at start and saves the queue and history in the upstream format at once; `e1035c09` (B54) makes that work on files the service can't write in place. On the server, all 2,299 state files are now format 7 (test: queue_format_test legacystates, upstream retries a converted history item).
